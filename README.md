# Helpera

Helpera — цифровая платформа для подбора волонтёрских задач с использованием интеллектуальных рекомендаций.

## О проекте

Платформа решает проблему неэффективного взаимодействия между волонтёрами и некоммерческими организациями (НКО).

В текущей практике:
- волонтёры тратят много времени на поиск подходящих задач  
- НКО получают нерелевантные отклики  
- часть задач остаётся без исполнителей  

Helpera улучшает этот процесс за счёт персонализированного подбора задач для волонтёров.

## Основная логика

Система:
- анализирует профиль волонтёра  
- сопоставляет его с задачами  
- формирует список наиболее релевантных задач  

Волонтёр откликается на задачи, а НКО самостоятельно выбирает исполнителя.

## Как это работает

1. НКО создаёт задачу (описание, требования, сроки)  
2. Волонтёр заполняет профиль (навыки, опыт, интересы)  
3. Система формирует персональные рекомендации задач  
4. Волонтёр откликается  
5. НКО рассматривает отклики и принимает решение  

## ML-логика

Модель оценивает вероятность успешного взаимодействия пары:

волонтёр + задача

Учитываются:
- совпадение навыков  
- формат участия  
- поведение (просмотры, отклики)  
- решения НКО  
- факт выполнения и оценки  

## Данные

Система фиксирует события:
- показ и просмотр задачи  
- отклик волонтёра  
- принятие или отклонение НКО  
- завершение задачи  
- отзывы  

На основе этих данных формируется датасет для обучения модели.

### ML-слой данных

`supabase-schema.sql` содержит таблицы и представления для данных модели:
- `ml_source_*` — импорт приложенных синтетических CSV как baseline.
- `ml_events` и `ml_event_log` — production-журнал событий в формате датасета.
- `ml_volunteers`, `ml_ngos`, `ml_tasks` — нормализованные срезы профилей и задач.
- `ml_ranking_examples` — обучающие пары volunteer-task из финального ranking dataset.
- `ml_ranking_dataset_base` — базовая production-выгрузка пар по реальным событиям.

Синтетические CSV лежат в `datasets/`. После применения схемы импорт заполняет и продуктовые таблицы Supabase (`volunteer_profiles`, `ngo_profiles`, `tasks`), и ML-таблицы:

```bash
python3 scripts/import_ml_datasets.py
```

Если в удалённой Supabase ещё не применён обновлённый `supabase-schema.sql`, можно сначала наполнить только продуктовые таблицы:

```bash
python3 scripts/import_ml_datasets.py --skip-ml
```

## Ценность

Для волонтёров:
- быстрее находят подходящие задачи  

Для НКО:
- получают более релевантные отклики  
- сокращают время на отбор  

## Технологии

- Frontend: HTML, CSS, JavaScript  
- Backend: FastAPI  
- База данных: PostgreSQL / Supabase  
- ML: Learning-to-Rank  

## Цель

Повысить эффективность распределения волонтёрских задач и улучшить качество взаимодействия между волонтёрами и НКО.
